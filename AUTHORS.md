## Co-authorship convention

This project distinguishes the human who *prompted / directed* the work from the model that *wrote* the code. Both get credited.

If you contribute changes that were materially produced with AI assistance, add **two** trailers to your commit message:

```
Prompted-By: Your Name <you@example.com>
Co-Authored-By: Claude Opus 4.7 (1M context) <noreply@anthropic.com>
```

- `Prompted-By:` — the human who directed the work. Non-standard but increasingly common in AI-assisted projects; it accurately reflects roles when you didn't physically write the code.
- `Co-Authored-By:` — the model that produced the code. GitHub recognizes this trailer and graphs it in the contribution timeline.

If a contributor's git-config email differs from their GitHub-recognized email, add a second `Co-Authored-By:` line so GitHub still graphs the contribution to their profile.

Use the model identifier you actually used (e.g. `Claude Sonnet 4.6`, `GPT-5`, etc.). Don't invent versions. See [CONTRIBUTING.md](CONTRIBUTING.md) for the full commit-message format.
